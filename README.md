# FT2 Toolkit

> [!IMPORTANT]
> **Single-player only.** FT2 Toolkit works only on an offline, single-player farm. It never works in multiplayer: when the game is hosting or joining an online session, or playing split-screen co-op, every feature switches off and the game goes back to normal.

A free, open-source trainer for **Farm Together 2** on PC (Steam, Windows). It is plain Python with a small window, so there is no exe to trust and every line of code can be read.

## Features

**Tractor**
- Auto tractor speed, adjustable live (F6 toggles it in game)
- Bigger work area: 5×5, 7×7 or 9×9
- Infinite fuel

**Player**
- Faster walking, running and manual driving
- Camera can zoom further out
- Faster house, town, teleport and vehicle transitions

**Farm**
- Instant grow for crops, flowers, herbs, trees, animals and fish

## How to use

1. Install [Python](https://www.python.org/downloads/) 3.10 or newer (64-bit).
2. Download this repository (**Code → Download ZIP**) and extract it.
3. Start Farm Together 2 and load a single-player farm.
4. Double-click `FT2Toolkit.pyw`.

Settings are saved automatically, and the game returns to normal when you close the window. Back up your save before using instant grow.
